# 高效學習法 LLM Wiki 與教學簡報

```
index.html          首頁
CLAUDE.md           Wiki 規則（給 AI 的）
raw/                原始資料擷取（不修改）
wiki/               index.md、log.md、sources/、concepts/（另有 .html 網頁版）
slides/index.html   教學簡報
workflow/           流程圖、稿件 v1/v2、檢查腳本與結果、執行紀錄
```

簡報由 `workflow/draft_v3.json` 經 `build_slides.py` 產生；網頁版 Wiki 由 `build_wiki.py` 產生。
